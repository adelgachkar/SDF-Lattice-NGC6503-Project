# Data provenance

## `NGC6503_rotmod.dat`

The verbatim SPARC mass-model file for NGC 6503 (Lelli, McGaugh & Schombert 2016, AJ 152, 157), taken unchanged from the official `Rotmod_LTG` archive. No reformatting, no unit conversion, no rounding.

| Field | Value |
| :--- | :--- |
| File | `NGC6503_rotmod.dat` |
| Bytes | 1509 |
| MD5 | `a9e481e375d7ed7d430342f406e917b1` |
| Rows | 31 radial bins, $0.76 \le r \le 23.50$ kpc |
| Adopted distance in file | **6.26 Mpc** |

### Retrieved from two independent copies, byte-identical

1. **Zenodo** record [16284118](https://zenodo.org/records/16284118), file `Rotmod_LTG.zip` (110 737 bytes, the official archive of all 175 galaxies). Extracted member `NGC6503_rotmod.dat`.
2. **GitHub mirror** `carsondowns-cte/Rotmod_LTG`, path `NGC6503_rotmod.dat`.

Both copies hash to `a9e481e375d7ed7d430342f406e917b1`. A third independent transcription (`dmf-sparc.com`) reproduces the same radius/velocity/gas/disk values row for row.

The canonical host `astroweb.cwru.edu/SPARC` (formerly `astroweb.case.edu/SPARC`) was **unreachable** at retrieval time (connection timeout on both ports), which is why the mirrors above were used. If you can reach the host, verify with:

```
curl -O http://astroweb.cwru.edu/SPARC/Rotmod_LTG.zip
md5sum Rotmod_LTG.zip   # expected e4c8b92766026770ed35e5889064e12b for the zip
```

### Columns

Whitespace-separated, three `#` comment lines then 31 data rows:

| Col | Name | Unit | Meaning |
| :-- | :--- | :--- | :--- |
| 1 | `Rad` | kpc | Galactocentric radius |
| 2 | `Vobs` | km/s | Observed circular velocity |
| 3 | `errV` | km/s | $1\sigma$ uncertainty on `Vobs` |
| 4 | `Vgas` | km/s | Gas contribution (may be signed) |
| 5 | `Vdisk` | km/s | Stellar disk contribution, normalised to $\Upsilon_{\rm disk}=1$ |
| 6 | `Vbul` | km/s | Bulge contribution, normalised to $\Upsilon_{\rm bul}=1$ (zero for NGC 6503) |
| 7 | `SBdisk` | $L_\odot/{\rm pc}^2$ | Disk surface brightness at 3.6 µm |
| 8 | `SBbul` | $L_\odot/{\rm pc}^2$ | Bulge surface brightness at 3.6 µm |

The baryonic speed is constructed as

$$v_{\rm bar}^2 = V_{\rm gas}\lvert V_{\rm gas}\rvert + \Upsilon_{\rm disk}V_{\rm disk}^2 + \Upsilon_{\rm bul}V_{\rm bul}^2$$

The absolute value on the gas term is required because `Vgas` is negative where the gas distribution has a central depression.

## `ngc6503_sparc.csv`

A tidied, named-column copy of the same 31 rows, generated by `Scripts/radial_unfreezing_verification.py --export-csv`. It carries no information beyond the `.dat`; regenerate it rather than editing it.

## Two corrections this data forces on the manuscript

- **Distance, resolved.** The manuscript now adopts the file's own **6.26 Mpc**; the previously quoted $5.27 \pm 0.15$ Mpc (TRGB) is withdrawn as the adopted value because it had no reference and would have required rescaling the table. For the record, rescaling this file to 5.27 Mpc gives $\chi^2_\nu = 1.243$ for the adopted parameters instead of $1.320$ — the threshold verdict depends on the distance assumed. Reproduce with `python Scripts/radial_unfreezing_verification.py --fit --distance-mpc 5.27`.
- The previously bundled `ngc6503_audit_rows.csv` (7 rows at $r = 0.41, 1.23, 2.46, \dots$ kpc) is **not** a subset of SPARC. None of its radii or velocities appears in the official file. It has been removed. Any statistic computed from it — including the $\chi^2_\nu = 2.716$ quoted in earlier revisions of these documents — was computed on invented numbers and is superseded.
