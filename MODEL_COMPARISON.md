## What this does and does not establish

1. The $\zeta(r)$ transition closure reaches lower $\chi^2$ on this galaxy than NFW and MOND at equal or fewer parameters. The earlier comparison claiming MOND $\chi^2_\nu \approx 20.545$ is withdrawn (it had compared a six-parameter QVEX fit against MOND with no fitted $\Upsilon$).
2. MOND was not tuned to this galaxy; its $p=0$ prediction is still within a few km/s across most of the curve. The large $\chi^2$ arises because the SPARC error bars drop to $\approx 1$ km/s between 8 and 13 kpc, where standard-$\mu$ MOND sits $\approx 2.5$ km/s low. That is a real tension, not a pathology.
3. One galaxy is one galaxy. NGC 6503 has an unusually flat outer curve, a declining stellar-disk component in the inner kiloparsec, and an inflection near 2.28 kpc that gives every smooth profile trouble. The ranking here does not guarantee the same outcome across the full SPARC sample.
4. These are point estimates from a local Nelder-Mead search. No error bars on $\Delta$AIC, no posterior volume correction, no Markov-chain evidence ratio. We report only whether $\Delta$AIC exceeds the conventional thresholds ($>2$ positive, $>6$ strong, $>10$ decisive).
5. Two SDF fits run to bounds ($\Delta R \to 0.05$ kpc and $\Upsilon_{\rm disk} \to 0.01$). A parameter on a bound is not a measurement; it means the model is trying to turn itself into a different functional form (a step function or a baryon-free curve). Those rows carry warning markers for a reason.
6. The manuscript's own adopted parameter row remains $\chi^2_\nu = 1.320$ ($p=1$, fixed $\Upsilon=0.62, R_0=1.83, \Delta R=0.46, v_\infty=116.20$). That is the curve shown in the main figures; the $\chi^2_\nu = 1.198$ row does not replace it.
7. NFW is one specific halo shape. An isothermal or Burkert core would fit NGC 6503 better than NFW; this script fits only the Navarro-Frenk-White profile to keep the comparison bounded.
